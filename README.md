# Site de monitoramento de rotina de exercícios físicos focados em calistenia (similar ao Hevy)

# Principais propriedades:

# Organizar Treinos
Permite adicionar exercícios a uma lista de treinos do dia. Cada item exibe o nome do exercício e a data em que foi adicionado, com a opção de marcá-lo como concluído.
# Evolução
Exibe um gráfico em formato de escadaria mostrando o progresso dos treinos realizados, com destaque visual para o treino atual e um resumo dos exercícios concluídos no dia.
# Histórico
Apresenta os treinos realizados organizados por dia da semana, com os exercícios feitos e a data de cada sessão.
# Explicação de Treino
Biblioteca de exercícios separada por grupos musculares (parte superior e inferior), com vídeos demonstrativos e instruções passo a passo de execução.
# Login
Tela de autenticação com campos de e-mail e senha para acesso à conta do usuário.

## Como rodar:

```bash
npm install
npm run dev
```

Acesse [http://localhost:3000]

## Rotas:

| URL | Componente |
|-----|-----------|
| `/` | Home |
| `/training` | Organizar Treinos |
| `/evolution` | Evolução |
| `/history` | Histórico |
| `/training-explanation` | Explicação de Treino |
| `/login` | Login |
